# Global Brief

> 世界のいまを、3行で。

世界のニュースを短時間で把握できる、AI要約対応のニュースWebアプリです。

NewsAPIから取得した最新記事をClaude APIで3行に要約し、ニュースに苦手意識がある学生でも気軽に世界情勢へ触れられるようにしました。

## デモ

[Global Briefを開く](https://global-brief-00i2.onrender.com/)

> Renderの無料プランを利用しているため、初回表示に時間がかかる場合があります。

## 解決したい課題

大学の講義で世界情勢について質問された際、多くの学生が答えられない場面を目にしました。ニュースを読まない理由には、記事の長さ、難しい言葉、情報量の多さなど、読み始めるまでの心理的なハードルがあると考えました。

そこで、ニュースの要点を3行で把握でき、気になった記事だけを詳しく読めるサービスを開発しました。

## 主な機能

### ニュースの取得・要約

- NewsAPIから最新の日本語ニュースを取得
- Claude APIによる記事の3行要約
- 難しい表現を避けた、会話に近い文章での表示
- 広告、求人、セールなどの記事を除外
- 取得結果を30分間キャッシュし、APIへの重複リクエストを削減
- APIエラー時は、取得済みの記事を可能な範囲で表示

### 情報を理解するための機能

- 記事を「紛争・戦争」「環境・SDGs」「経済」「政治」「国際」に自動分類
- PCでは気になる単語をダブルクリックして意味を検索
- 元記事へのリンクから詳しい内容を確認
- 記事画像がない場合は、内容に合う画像をUnsplashから取得

### 記事への反応・共有

- 5種類のリアクション
- ニックネームによるコメント投稿
- ブラウザへの記事保存
- X、LINE、URLコピーによる共有
- PC・スマートフォンに対応したレスポンシブ表示
- ダークモード

## 処理の流れ

1. NewsAPIから最新の記事を取得
2. 日本語記事を判定し、広告性の高い記事を除外
3. Claude APIで本文を3行に要約
4. タイトルのキーワードからカテゴリを判定
5. 記事画像がない場合は、要約時に生成したキーワードを使ってUnsplashから画像を取得
6. 要約・画像・カテゴリをカード形式で表示

## 開発で工夫した点

### 読みやすい3行要約

単に文章を短くするだけでなく、大学生が友人へ伝えるような自然な話し言葉になるよう、Claude APIへの指示を設計しました。硬い表現や難しい専門用語を避け、ニュースに慣れていない人でも内容をつかみやすくしています。

### 不要な記事の除外

ニュース取得APIには、広告、求人、キャンペーンなども含まれる場合があります。取得元ドメインの指定、除外キーワード、日本語判定、AIによる判定を組み合わせ、サービスの目的に合う記事を表示するようにしました。

### API利用量と待ち時間の削減

要約結果と画像取得結果をキャッシュし、同じ記事に対する外部APIの重複呼び出しを防いでいます。また、ニュース一覧も30分間保持し、表示速度とAPI利用量のバランスを取りました。

### 元記事を読む導線

AI要約だけで完結させず、出典を表示して元記事へ移動できるようにしました。要約をニュースへの入口として使い、興味を持った内容を詳しく確認できる設計にしています。

## ローカルでの起動

### 必要環境

- Python 3
- NewsAPIのAPIキー
- Anthropic APIのAPIキー
- Unsplash APIのアクセスキー（記事画像の補完に使用・任意）

### セットアップ

```bash
git clone https://github.com/pyth0n-study/global-brief.git
cd global-brief
python -m venv .venv
```

Windowsの場合：

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

macOS / Linuxの場合：

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

プロジェクト直下に `.env` を作成します。

```env
NEWS_API_KEY=your_news_api_key
CLAUDE_API_KEY=your_claude_api_key
UNSPLASH_ACCESS_KEY=your_unsplash_access_key
```

アプリを起動します。

```bash
python app.py
```

ブラウザで `http://127.0.0.1:5000` を開きます。

## データと著作権

- ニュース記事の著作権は各配信元メディアに帰属します
- 本サービスにはAIが生成した要約が含まれます
- 詳細や正確な文脈は、必ず元記事から確認できる設計にしています
- コメントにはニックネーム、本文、投稿時刻を保存します
- APIキーは環境変数で管理します

## 現在の制約

- AIによる要約は、元記事の意味を完全に再現できない場合がある
- NewsAPIやClaude APIなど、外部サービスの利用状況に影響される
- スマートフォンではダブルクリックによる語彙検索を利用できない
- 表示するニュースは現在最大10件
- SQLiteを使用しているため、本格運用では永続化方法の見直しが必要
