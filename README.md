# 🌍 Global Brief
> 世界のいまを、3行で。

## 🔗 デモ
https://global-brief-00i2.onrender.com

## 💡 制作背景
大学の講義にて、世界情勢を問われた際に多くの学生が答えられませんでした。
ニュースへの心理的ハードルを下げるため個人開発しました。

## ✨ 機能
- リアルタイムニュース取得（NewsAPI）
- AIによる記事の自動要約（Claude API）
- 単語ダブルクリックで即検索
- PC・スマートフォン両方で閲覧可能(スマホフォンの場合検索機能非対応)

## 🛠️ 使用技術
Python / Flask / HTML / CSS / JavaScript / NewsAPI / Claude API / Render

## 🤖 開発スタイル
Claude Codeを活用したAI駆動開発を実践。AIへの指示出しと出力の検証を繰り返しながら開発しました。
